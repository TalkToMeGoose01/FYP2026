# 7_Handover

Documents for whoever continues this work. Read them in this order.

| File | What it gives you |
|---|---|
| `WORKFLOW.pdf` | One-page flowchart of the whole pipeline, naming the script at each step. `WORKFLOW.mmd` is the editable Mermaid source |
| `VERIFICATION.md` | The checks behind Table IV of the thesis and how to run them without a GPU |
| `DECISION_LOG.md` | Every research decision in date order, with the reason and the evidence file |
| `RISK_REGISTER_AND_NEXT_STEPS.md` | What could make a reported result wrong or narrower than it looks, with a suggested order of further work |
| `READING_ROADMAP.md` | The literature grouped by the decision it supports, a watch list of the 12 closest studies and further reading |
| `pipeline_overview.pdf` | A simpler six-box view of the pipeline drawn in September 2026 |
